# Smart Clinic Management System - User Stories

## Admin User Stories

### US-ADMIN-01: Manage User Accounts
As an Admin, I want to manage user accounts so that I can control access to the Smart Clinic Management System.

### US-ADMIN-02: Manage Doctors
As an Admin, I want to add, update, and remove doctor information so that the doctor records remain accurate and up to date.

### US-ADMIN-03: Manage Patients
As an Admin, I want to view and manage patient information so that patient records are maintained properly.

### US-ADMIN-04: Manage Appointments
As an Admin, I want to view and manage appointments so that I can ensure appointments are properly organized.

### US-ADMIN-05: Control System Access
As an Admin, I want to assign appropriate access to users so that users can only access the features relevant to their roles.

---

## Patient User Stories

### US-PATIENT-01: Register Account
As a Patient, I want to register for an account so that I can access the Patient Appointment Portal.

### US-PATIENT-02: View Doctors
As a Patient, I want to view available doctors so that I can choose a doctor based on my needs.

### US-PATIENT-03: Book Appointment
As a Patient, I want to book an appointment with a doctor so that I can receive medical consultation.

### US-PATIENT-04: View Appointments
As a Patient, I want to view my scheduled appointments so that I can keep track of my upcoming consultations.

### US-PATIENT-05: Manage Appointments
As a Patient, I want to cancel or reschedule my appointments so that I can manage my schedule when my availability changes.

### US-PATIENT-06: View Prescription
As a Patient, I want to view my prescriptions so that I can follow the treatment recommended by my doctor.

---

## Doctor User Stories

### US-DOCTOR-01: Manage Availability
As a Doctor, I want to manage my availability so that patients can book appointments during my available hours.

### US-DOCTOR-02: View Appointments
As a Doctor, I want to view my scheduled appointments so that I can prepare for consultations with my patients.

### US-DOCTOR-03: Manage Patient Records
As a Doctor, I want to view patient information so that I can understand the patient's medical history before providing treatment.

### US-DOCTOR-04: Create Prescription
As a Doctor, I want to create prescriptions for patients so that I can provide appropriate treatment instructions.

### US-DOCTOR-05: Update Prescription
As a Doctor, I want to update patient prescriptions when necessary so that the treatment information remains accurate.

### US-DOCTOR-06: Manage Appointment Status
As a Doctor, I want to update the status of appointments so that patients and administrators can see whether an appointment is scheduled, completed, or cancelled.
